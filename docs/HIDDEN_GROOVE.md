# Hidden Groove Layer

> Not every musical expression exists in notation.
>
> Some of the most important information exists between events.

---

# Introduction

Traditional rhythm analysis primarily evaluates measurable timing.

Examples include:

- BPM
- Quantization
- Beat alignment
- Note onset timing

While these metrics are useful, they describe only part of a musical performance.

Professional musicians routinely communicate expression through subtle characteristics that are difficult to represent using conventional notation or MIDI events.

One Timeline Labs refers to this collection of characteristics as the **Hidden Groove Layer**.

---

# Hypothesis

Every performed note contains multiple observable dimensions.

These include:

- Timing
- Energy
- Transient development
- Dynamic envelope
- Spectral evolution
- Interaction with surrounding events
- Spatial behavior

Together, these dimensions contribute to what musicians commonly describe as "groove."

---

# Philosophy

Groove is not only where a note begins.

Groove is how musical energy evolves through time.
