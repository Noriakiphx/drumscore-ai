# DrumScore AI — One Timeline Labs

> Technology should never replace musicians.  
> It should help them understand, preserve, and improve their own musical expression.

Integrated MVP: audio upload, Performance Fingerprint v0.1, Invisible Groove research view, Live Guide Cue Layer, Score JSON foundation, FastAPI, Next.js, and Docker.

## Start
```bash
docker compose up --build
```
Frontend: http://localhost:3000  
API docs: http://localhost:8000/docs
